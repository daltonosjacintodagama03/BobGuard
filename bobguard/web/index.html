Sobre o BobGuard

🛡️

Segurança Proativa

Identifica vulnerabilidades antes que se tornem problemas reais. Análise profunda de código com foco em segurança.

🤖

Powered by Bob Shell

Integração com Bob Shell para análises contextuais e sugestões inteligentes baseadas nas melhores práticas de segurança.

📊

Roadmaps Personalizados

Gera planos de ação detalhados para corrigir vulnerabilidades, priorizando por severidade e impacto.

Funcionalidades Principais

01

Análise Automática de Código

Escaneia automaticamente seu projeto em busca de vulnerabilidades conhecidas, código inseguro e más práticas de segurança.

02

Detecção de Vulnerabilidades

Identifica SQL Injection, XSS, CSRF, exposição de dados sensíveis, e outras vulnerabilidades comuns do OWASP Top 10.

03

Navegação Inteligente

Interface sidebar integrada ao VS Code para navegar facilmente entre vulnerabilidades encontradas e suas localizações no código.

04

Geração de Roadmaps

Cria planos de correção passo-a-passo, com priorização automática baseada em severidade e contexto do projeto.

05

Sincronização Cloud

Salva análises e roadmaps no Firebase, permitindo acesso de qualquer lugar e colaboração entre equipes.

06

Cache Local

Funciona offline com cache local, sincronizando automaticamente quando a conexão é restaurada.

Como Usar

1

Instalação

Clone o repositório e instale as dependências:

git clone git@github.com:daltonosjacintodagama03/BobGuard.git
cd BobGuard
docker-compose up -d

Ou instale diretamente no VS Code via marketplace (em breve)

2

Configuração

Faça login com sua conta Google ou email:

  • Abra o VS Code
  • Pressione Ctrl+Shift+P (ou Cmd+Shift+P no Mac)
  • Digite "BobGuard: Login"
  • Complete o processo de autenticação
3

Análise

Execute a análise de segurança:

  • Abra seu projeto no VS Code
  • Pressione Ctrl+Shift+P
  • Digite "BobGuard: Analyze Project"
  • Aguarde a conclusão da análise
4

Correção

Navegue pelos resultados e corrija vulnerabilidades:

  • Abra a sidebar do BobGuard
  • Clique em uma vulnerabilidade para ver detalhes
  • Gere um roadmap de correção
  • Siga as instruções passo-a-passo

Perguntas Frequentes

O BobGuard funciona com qualquer linguagem de programação?

Atualmente, o BobGuard tem melhor suporte para JavaScript, TypeScript, Python, Java e PHP. Estamos constantemente expandindo o suporte para mais linguagens.

Preciso de conexão à internet para usar?

Não necessariamente. O BobGuard funciona offline com cache local. A conexão é necessária apenas para sincronização cloud e geração de roadmaps com IA.

Meus dados de código são enviados para algum servidor?

Apenas metadados e resultados de análise são armazenados no Firebase. O código fonte permanece local e nunca é enviado para servidores externos.

Como o BobGuard se compara a outras ferramentas de segurança?

O BobGuard combina análise estática tradicional com IA contextual do Bob Shell, oferecendo não apenas detecção, mas também roadmaps personalizados de correção.

Posso usar o BobGuard em projetos comerciais?

Sim! O BobGuard é open source e pode ser usado livremente em projetos pessoais e comerciais. Veja a licença no repositório para mais detalhes.

Como posso contribuir para o projeto?

Contribuições são bem-vindas! Visite nosso repositório no GitHub, abra issues para bugs ou sugestões, e envie pull requests com melhorias.
